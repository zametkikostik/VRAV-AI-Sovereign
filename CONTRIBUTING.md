# Contributing to VRAV AI

1. Sovereign by default — no hard OpenAI/Anthropic dependency.
2. Safety first — do not weaken injection/policy/sandbox without a stronger replacement.
3. MIT attribution — keep LICENSE/NOTICE.

```bash
pip install -r requirements.txt pytest pytest-cov
make test
```

PRs: focused branch, tests, describe why. Security issues: private report to maintainer.
