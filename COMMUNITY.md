# Community

## Enable on GitHub (maintainer)

1. **Discussions** — Settings → General → Features → Discussions
2. **Codecov** — https://codecov.io → add repo → copy upload token →  
   GitHub → Settings → Secrets and variables → Actions → `CODECOV_TOKEN`
3. **Security advisories** — Settings → Code security → Private vulnerability reporting

## Board (optional Projects)

Create a Project board: `Backlog` · `In progress` · `Review` · `Done`  
Labels: `bug`, `enhancement`, `security`, `docs`, `good first issue`, `help wanted`.

See [CONTRIBUTING.md](CONTRIBUTING.md).
